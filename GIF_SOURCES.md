# GIF sources

The app bundles 200 real animated GIF files during the GitHub Actions build.

Source:
- Animated Country Flags: https://github.com/open-assets-hub/animated-country-flags
- License: MIT
- Assets used: 100 waving flags + 100 circle-wave flags, 128px versions.

The build downloads the assets at build time and packages them into the APK, so the installed app can display them offline.
