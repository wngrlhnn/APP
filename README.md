# GIF Gallery

אפליקציית Android עם **200 GIFים אמיתיים ומונפשים** שנארזים בתוך ה-APK.

## תכונות
- 200 GIFים מונפשים.
- 100 GIFים בסגנון גלים + 100 בסגנון מעגל.
- חיפוש.
- סינון לפי קטגוריה.
- מועדפים.
- פתיחת GIF בתצוגה גדולה.
- אייקון ייעודי לאפליקציה.
- צפייה אופליין לאחר ההתקנה.

## מקור ה-GIFים
ה-GIFים מגיעים מפרויקט Animated Country Flags, שמופץ ברישיון MIT:
https://github.com/open-assets-hub/animated-country-flags

ה-GIFים מורדים בזמן בניית ה-APK ונארזים בתוך האפליקציה, כך שלא נדרש אינטרנט כדי לנגן אותם לאחר ההתקנה.
