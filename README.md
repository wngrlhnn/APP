# Jeep Explorer

אפליקציית Android אופליין עם גלריית ג׳יפים גדולה.

- 30 כרטיסי ג׳יפים עם תמונות רכב אמיתיות.
- חיפוש לפי שם ותיאור.
- סינון לפי שטח, פיקאפ, משפחתיים וחשמליים.
- מועדפים.
- תמונות מורדות בזמן בניית ה-APK ונארזות בתוך האפליקציה, כך שאפשר להשתמש בגלריה בלי אינטרנט.
- אייקון האפליקציה נוצר מצילום ג׳יפ חופשי לשימוש ונארז בתוך ה-APK.
