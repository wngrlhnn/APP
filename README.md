# GIF Gallery

אפליקציית Android עם **5,000+ GIFים אמיתיים ומונפשים**, ארוזים בתוך ה-APK לצפייה מלאה ללא אינטרנט.

## תכונות

- 5,000+ GIFים אמיתיים שהורדו מ-Wikimedia Commons בזמן הבנייה.
- קטגוריות: מצחיק, חיות, אפקטים, תגובות ועוד.
- חיפוש וסינון מקומי.
- מועדפים.
- פתיחת GIF בתצוגה גדולה.
- חזרה באנדרואיד למסך הגלריה במקום יציאה מהאפליקציה.
- דחיסה ל-128px, עד 16 פריימים ו-96 צבעים כדי לצמצם משמעותית את נפח האפליקציה.
- אין צורך באינטרנט לאחר ההתקנה.

## בנייה

GitHub Actions מוריד את ה-GIFים, דוחס אותם ומכניס אותם ל-APK בזמן הבנייה.
